📌 How to start work each time (important — always do this)

Every time you want to work on the 100k Parent site, start like this:

1. Find the 100kParent icon on your Desktop — the one we set up before. Double-click it.
2. A black window opens and does its thing. It's grabbing the latest version of the site (including anything I've changed) so you're never working on an old copy. Give it a few seconds.
3. Claude Code opens automatically. Once it's open, describe what you want to change like normal.

That's it. The double-click pulls the latest and opens everything — you don't type any commands.

The golden rule: always start by double-clicking 100kParent. Don't open Claude Code on its own, and don't reuse a window you left open from yesterday.

If you forget to double-click it and realise you've already started:
Don't panic and don't keep working. Before you do anything else, paste this into Claude Code:
"Before I make any changes — pull the latest from GitHub first and tell me if anything came down. If there are any conflicts with work I've already started, stop and tell me rather than continuing."

If it says it pulled changes cleanly, carry on. If it mentions a conflict or a problem, stop and message me before doing anything else — don't try to fix it yourself, and don't push. That's the one situation where we could lose work, so it's always worth a quick check with me rather than guessing.
